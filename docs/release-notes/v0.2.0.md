# CWM v0.2.0 - notatki wydania (szkic)

## Summary (English)

CWM v0.2.0 renames the product to CWM - Claude Workspace Manager and adds the `cwm` command line
tool next to the desktop app. The CLI starts Claude Code with a reviewed, pinned set of resources
(`cwm start`, `cwm run`, `cwm diff`, `cwm lock`), supports local and git plugins with offline
integrity checks, and asks for approval before anything the engine would execute. Data from v0.1.0
is migrated on first start. This release also adds an MIT license, third-party notices, and
process-level crash logging. Builds are unsigned (see `docs/INSTALACJA.md`); verify downloads with
`SHA256SUMS`.

## Najważniejsze zmiany

- **Nowa nazwa i polecenie `cwm`.** Produkt nazywa się CWM - Claude Workspace Manager (dawniej
  Universal AI Skills Manager). Katalog danych to `<appData>/CWM`, a dane z v0.1.0 są kopiowane
  przy pierwszym starcie.
- **CLI.** `cwm start`, `cwm run`, `cwm diff`, `cwm lock`, `cwm sync`, `cwm import claude`,
  `cwm plugin`, `cwm workflow`, `cwm engine check`. Szczegóły: `docs/CLI.md`.
- **Ochrona zasobów.** Zatwierdzanie przy pierwszym użyciu i po zmianie treści, pokazywanie
  wstawek `!`, piny skryptów hooków, plugin z git przypięty do commitu i sprawdzany offline.
- **Licencja MIT** i `THIRD_PARTY_NOTICES.md` z listą zależności produkcyjnych.
- **Odporność na awarie.** Nieobsłużone wyjątki i awarie procesów są zapisywane w logu bez
  sekretów, a po awarii renderera okno jest przeładowywane.

Pełna lista: `CHANGELOG.md`, sekcja `[0.2.0]`.

## Uwaga przy aktualizacji

- Na Windowsie zmienił się identyfikator aplikacji: v0.2.0 instaluje się obok v0.1.0, więc
  najpierw odinstaluj v0.1.0. Dane zostają i są migrowane.
- Kopie pluginów z git pobrane wcześniej wymagają jednorazowego `cwm plugin fetch <id>`.
- Zasoby z wstawkami `!` zapytają o zatwierdzenie ponownie przy `cwm start`.

## Pliki i weryfikacja

Pliki do pobrania: DMG i ZIP (macOS arm64, x64), instalator i wersja portable (Windows),
AppImage i deb (Linux). Wydania nie są podpisane, więc system może ostrzec przy pierwszym
uruchomieniu. Sprawdź sumy kontrolne z `SHA256SUMS` (`shasum -a 256 -c SHA256SUMS`).
Instrukcja: `docs/INSTALACJA.md`.
