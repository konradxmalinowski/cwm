Wersjonowanie biblioteki w Git

Po każdej operacji, która zmienia bibliotekę (zapis, usunięcie, naprawa, import), aplikacja zapisuje commit w lokalnym repozytorium. Repozytorium leży obok biblioteki w katalogu danych aplikacji, nie ma zdalnego adresu i niczego nie wysyła. Funkcja jest opcjonalna: bez Git albo po wyłączeniu biblioteka działa tak samo. Wyłączenie nie usuwa repozytorium.

Domyślnie do historii trafiają tylko elementy o zakresie publicznym, a większość elementów jest prywatna. Elementy, w których wykryto sekrety, nie trafiają do historii nigdy, także po zaznaczeniu tej opcji, bo treść jest skanowana ponownie przy każdym commicie. Wycofanie zgody zdejmuje elementy z kolejnych commitów, ale nie usuwa ich z commitów, które już powstały.
